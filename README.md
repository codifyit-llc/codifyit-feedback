# CodifyIT Feedback

Welcome to CodifyIT's public feedback space.

This repo is where clients, users, and interested operators can share:

- ideas
- product improvements
- enhancement requests
- cross-product feedback

## Use Statement

- **Owner:** CodifyIT LLC
- **Purpose:** public ideas and product feedback through GitHub Discussions
  only
- **Not for:** implementation work tracking, support incidents, security
  disclosures, billing or contract questions, secrets, confidential content,
  or client-specific details
- **Work tracker:** public Issues stay disabled; accepted work routes into
  `codifyit-os` or the relevant product repo
- **Discussion route:** public GitHub Discussions in this repo
- **Inherited governance:** inherits public-intake, security, confidentiality,
  and moderation rules from `codifyit-os`
- **Governance mirror:** `docs/contracts/codifyit-governance-inheritance.md`

## What this repo is for

Use GitHub Discussions here when you want to tell us:

- what is not working well from your perspective
- what you wish a CodifyIT product or workflow did better
- what new idea you think is worth evaluating
- where multiple CodifyIT products or experiences could connect more cleanly

## What this repo is not for

Please do not use this repo for:

- bug reports that need immediate triage
- security disclosures
- billing or contract questions
- confidential or client-specific implementation details
- public tracking of development work

If your request falls into one of those categories, use the private or direct
channel already established with CodifyIT.

## How we respond

We keep public responses simple and visible:

- `[Needs Clarification]`
- `[Under Review]`
- `[Watchlist]`
- `[Routed]`
- `[Declined]`

Those statuses tell you what is happening next without exposing CodifyIT's
internal governance or downstream work management.

## How to post

Start a discussion in **Ideas**, **Product Improvements**, or **Cross-Product
Feedback**. Each category has a short form. Pick the product it concerns
(Compass, Atlas, Aria, Aaron, Recon, Sage, or cross-product) and tell us:

- the problem or opportunity you see
- the outcome you want
- who is affected
- any workaround you are using today

The form asks you to confirm the post holds no confidential or client-specific
information. If it would, use the private channel you already have with
CodifyIT instead.

**Compass adopters:** this is where to send framework feedback to CodifyIT.
Choose **Compass** as the product. Issues are not used here. Discussions are the
one door.

CodifyIT reviews every post and decides what becomes tracked work. A person,
not a bot, replies with one of the statuses above.

## Important note

This repo is a feedback and communication surface. Approved ideas may move into
internal review or a product repo later, but that work will not be managed
publicly here.
